- форма нового проекта подключена к схеме Supabase `donelvit`;

## Установка поверх текущей версии

1. Остановите сервер сочетанием `Ctrl + C`.
2. Сделайте резервную копию текущей папки проекта.
3. Распакуйте этот архив.
4. Скопируйте его содержимое в:
   `D:\DONELVIT\DONELVIT_OS_v0.1_Foundation`
5. Подтвердите замену файлов.
6. Не удаляйте существующий `.env.local`.
7. Выполните:

```powershell
npm.cmd run dev
```

8. Откройте:

`http://localhost:3000/projects/new`

## Проверка

После запуска должна открыться форма создания проекта без ошибки компиляции.
