# DONELVIT OS v0.4 — Карточка проекта

## Добавлено
- полноценная карточка проекта;
- вкладки: Общие, Системы, Документы, Экспертиза, Финансы, История;
- реальные инженерные системы из `project_systems`;
- реальные документы из `documents`;
- индикаторы готовности и быстрые интеграции;
- подготовленная структура модулей экспертизы и финансов.

## Установка
1. Остановить сервер: `Ctrl + C`.
2. Скопировать содержимое архива поверх текущего проекта.
3. Сохранить существующий `.env.local`.
4. Удалить `.next`:
   `Remove-Item -Recurse -Force .next`
5. Запустить:
   `npm.cmd run dev`
6. Открыть любой проект и нажать его номер.
